# 🌍 TravelEase

**TravelEase** is a vehicle booking platform that makes travel easier and more convenient. Users can explore, book, and manage vehicles with just a few clicks — all in one place!  
<img src="https://github.com/tamanna-hash/assignment-10-travel-ease-client/blob/main/travelease.png?raw=true" height="300px" width="400px">

🔗 **Live Site:** [TravelEase Website](https://t-travelease.netlify.app/)

---

## ✨ Features

- 🚗 **Book Vehicles Easily:** Browse and book available vehicles for your trips in just a few clicks.  
- 👤 **User Authentication:** Secure login and registration using **Firebase** (Google & Email/Password).  
- 🛠️ **Manage Your Vehicles:** Authenticated users can **add**, **update**, and **delete** their own vehicle listings.  
- 🔍 **Smart Search & Sort:** Find vehicles by name or **sort by price** to get the best deal.  
- 📋 **My Bookings Page:** View all your booked vehicles and manage them from your personal dashboard.  

---

## 🧰 Technologies Used

- **React.js** – Frontend framework  
- **Node.js & Express.js** – Backend server  
- **MongoDB** – Database  
- **Firebase Authentication** – User login system  
- **Tailwind CSS and DaisyUI** – Styling and responsive design
